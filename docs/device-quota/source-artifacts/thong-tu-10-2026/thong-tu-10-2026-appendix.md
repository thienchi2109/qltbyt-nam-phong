## Chú thích

- ¹ Tiêu chuẩn, định mức không phụ thuộc số lượng máy xét nghiệm. Áp dụng tương tự đối với các Máy xét nghiệm khác.
- * Đơn vị quy định tại Phụ lục này là bộ phận hoạt động chuyên môn thực hiện một hoặc một số lĩnh vực chuyên môn y tế thuộc cơ cấu tổ chức của đơn vị sự nghiệp công lập trong lĩnh vực y tế.
- ** Định mức sử dụng được xác định theo nguyên tắc làm tròn số lên. Áp dụng nguyên tắc làm tròn số lên cho tất cả thiết bị y tế khi tính định mức.

## React mapping suggestion

```ts
type TableRow =
  | { type: "section"; id: string; tt: string; name: string }
  | { type: "item"; id: string; tt: string; parent?: string | null; name: string; unit: string; quota: string[] }
```

Use `section` rows as `<tr><td colSpan={4}>...</td></tr>` and `item` rows as normal four-column rows. Keep `quota` as an array so the editable UI can render each condition as a separate multiline item.
